🧐 Project Overview
The Sushi Restaurant Website is designed to provide an online presence for a sushi restaurant. It serves as a showcase of the restaurant’s offerings, including its menu, special dishes, location, and contact information. The website also features dynamic and interactive content such as a menu with images, an online reservation system, and customer reviews.

The website is built using:

HTML for the structure of the pages.
CSS for styling, making the website visually appealing and responsive.
JavaScript for interactive features such as a reservation form, dynamic content updates, and smooth scrolling effects.
💻 Technologies Used
HTML:

Used to build the core structure of the website, including headers, footers, navigation menus, and content sections.
CSS:

Used to style the website, ensuring that it is visually appealing with an easy-to-navigate layout.
It also ensures the website is responsive and adapts to various screen sizes.
JavaScript:

Powers interactive elements such as reservation forms, gallery sliders, and dynamic content transitions for a better user experience.
✨ Features
🏠 Home Page:

An introduction to the restaurant with visually appealing images of sushi, information about the restaurant's atmosphere, and key features of our restaurant.
🍣 Menu Page:

A digital menu showcasing various sushi options, from classic rolls to chef's specials. Each item includes images, descriptions, and prices.
📅 Reservation System:

A form for customers to make reservations, ensuring they can book a table ahead of time.
📍 Location & Contact Info:

A section featuring the restaurant's address, phone number, and an embedded Google map to make it easy for customers to find us.
📝 Customer Reviews:

A dynamic section where customers can view reviews and feedback about the restaurant. This can include star ratings and testimonial quotes.
🍱 Specials & Promotions:

A dedicated section for showcasing current specials, promotions, and new menu items to keep customers informed and excited.
📱 Responsive Design:

The website is designed to be fully responsive, providing a smooth experience across all devices, including mobile phones, tablets, and desktop computers.
🎨 JavaScript Interactivity:

Interactive features like pop-up reservation forms, smooth scrolling, and image sliders to create a dynamic user experience.
